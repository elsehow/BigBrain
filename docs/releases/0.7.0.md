# BigBrain 0.7.0

That Tracks now connects from Integrations with a read-only API key. The
first connection imports all permitted history, including archived trackers
and complete journal/dream text. New entries, corrections and deletions sync
every minute while BigBrain is running, with automatic catch-up after downtime.

Each event is a readable source with its original structured record. Corrections
supersede earlier versions; deletions withdraw the source from current evidence
while preserving its history. Turning the integration off stops future collection.

Granola and That Tracks now show connection status, the last successful check,
and failures beside their switches. A successful check is reported even when
nothing new arrived. That Tracks keys are validated before connecting.

In That Tracks: Settings → Account & sync → API keys → create a read-only key
named BigBrain. In BigBrain: Integrations → That Tracks → turn on and paste it.
