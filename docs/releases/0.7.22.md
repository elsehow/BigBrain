# BigBrain 0.7.22

- Window expansion moves to the upper-right and appears with the navigation controls. AeroSpace-managed windows use its fullscreen mode; other macOS windows expand without entering a separate Space, keeping Escape available for navigation.
- Agent chats share consistent title, message, and composer alignment in sidebar and full-width views, with improved indicator spacing and Back/Esc padding.
- Option-H and Option-L collapse and expand the agent pane even while typing.
- The model picker closes with the checkmark when unchanged. Escape dismisses the picker before leaving the conversation.
- Note sidebars give the title, summary, and connected records more room with wider gutters and more vertical spacing.
- Shift-Enter keeps the new line visible in the agent composer.
