# BigBrain 0.7.12

Unread mail status now refreshes when you return to the app, recovers from
interrupted connections, and offers a retry when the provider is unavailable.
Search and recent sources show current unread status across thread aliases,
with compact, single-line rows.

You can now hide keyboard hints in settings. The preference is remembered
across windows and restarts, and note headers become more compact when hints
are hidden.
