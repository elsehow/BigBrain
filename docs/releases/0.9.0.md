# BigBrain 0.9.0

- **Desktops run in a sandbox.** Every command a Desktop's agent runs is confined to its own folder or the project it is working in. It can't read your keys, passwords, mail, messages or browser data, or your vault's files directly. Its network reaches package registries and GitHub, plus any hosts you add in Settings → Models → Desktop network. Land now shows the commits and the diff before it pushes.
- **Outside material turns a Desktop's shell off.** A Desktop started from, or that reads, an email, a feed item, a meeting note or another outside source can't run commands until you click **Allow shell for this desktop**. The Desktop shows the command its agent asked to run, and its running servers stop.
- **Agents see where things came from.** What Pilot, Desktops and connected agents such as Claude Code and Codex read through BigBrain says where it came from and whether it's yours; outside text is marked as data, not instructions. Sign-in codes and password-reset or verification links are withheld from agents everywhere, with no Jev key needed. A sign-in email under ten minutes old shows agents only its sender, subject and date. Other new mail reaches them at once.
- **The viewer needs this launch's session.** The app signs itself in. To open BigBrain in a browser, here or over `ssh -L`, run `bigbrain open`.
- **Images in notes an agent wrote** load only when you click **Load image**.
- **Files you open from a source** are checked by Gatekeeper like any download. Apps, installers and scripts are shown in Finder instead of opened.
- **Pilot's folders.** Pilot can't be given your whole home folder, or a folder that holds credentials. Folders you had added that are now too broad are listed under Removed in Settings with the reason. Inside the folders it reads, Pilot skips key and credential files, `.env` files and `.git`.
- **Private files.** BigBrain's settings folder, your vault's `.env` and its logs are readable only by you.
- **Your keys stay with BigBrain.** Provider keys in your vault are no longer passed to every program BigBrain starts. If you use Amazon Bedrock with access keys in the vault, switch to an AWS profile (`AWS_PROFILE`).
- **A new update key.** This release moves the app onto a new signing key for updates. Nothing to do: later updates arrive as before.
- **Desktops** start on the Pilot model chosen in Settings, reopen instantly, and show a sent message at once. Shift+Esc archives the open Desktop.
- **Also:** integration accounts start collapsed in Settings; the intake firewall no longer blocks ordinary browser clips; the Field draws dots a little heavier and edges finer.

Verification: the full engine suite (2353 tests), the desktop's Rust tests and the real-sandbox tests pass on the release commit.
