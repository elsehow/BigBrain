# BigBrain 0.7.21

Memories now organize the home graph. Browse them with J/K, preview their summaries in a translucent bottom HUD, and press Enter to open their connections. Memory browsing wraps around and pans the graph to keep the selected memory visible.

A unified sidebar brings search, recent items, agents, and settings together. Search uses /; Recents uses R with U for unread. Select multiple search or recent items with X, attach a Pilot with Shift-Enter, or mark them read with Shift-U.

Pilot mentions and Quick summaries share context-based connection ordering. Successful memory passes prepare cached summaries. Agent controls are more compact, status indicators match the graph, and Escape returns a chat to its agent list.

Graph edges adapt to theme colors for readable contrast. Memory neighborhoods emphasize direct relationships and reveal second-degree context without the dense mesh of unrelated links.
