# BigBrain 0.2.5

Connect Codex or Claude Code, and choose one model for your vault.

- First run lets you choose which agent to connect. Settings uses the same
  connection controls for both agents, with accurate status for each.
- Vault settings has one model selector for gardener and memory, listing
  models from available agents. Codex can curate using your existing login.
- Codex can search your vault, add notes, load memory, and capture chats.
  Its plugin and the Claude Code plugin share generated skills and scripts
  so improvements stay in sync. Codex requires version 0.153.4 or newer;
  approve BigBrain's hooks in Codex's `/hooks` to enable memory and capture.
- The macOS title bar follows your theme, including custom skins.
- The text drawer stays steady while you type: search results retain their
  space while loading, and typing clears the hovered result's camera focus.
- Includes the 0.2.4 fix for clicking the update banner over the graph.
