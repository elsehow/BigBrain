# BigBrain 0.7.16

Existing worker conversations now appear in Pilots, keeping their history and
context together with new conversations.

Search ranks results by relevance and importance across the omnibox and Pilot
context picker, making useful sources easier to find.

The website has a refreshed landing page with a preview of the app's palettes.
The installer sends no telemetry; website metrics count button clicks and
download requests only.
