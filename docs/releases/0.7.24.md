# BigBrain 0.7.24

- Sidebar views share square selection bars, block scrollbars, consistent headers, and clearer keyboard hints that preserve layout when hidden.
- Agent notifications appear in the text preview and agent list. Opening a conversation marks its notifications read; unanswered notifications can be marked unread, and sending a turn clears them.
- Previous/Next and h/l move through the agent list. Notes use browser-style history arrows with unavailable directions dimmed.
- Escape leaves the chat input before leaving the conversation, and home controls fade away when dismissed.
- The update banner matches the sidebar theme. Graph motion trails use the correct theme color and fade sharply with depth.
- Removed the global quick picker for now.
