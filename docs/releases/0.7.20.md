# BigBrain 0.7.20

Active Pilot conversations bring their direct connections forward in the
graph, including between turns. Unrelated nodes recede to 10% visibility.
Closing the conversations restores the normal overview; selecting a note
still focuses its neighborhood.

Removed obsolete worker graph and roster logic. Historical conversations,
links, and outputs remain available through their migrated Pilots.

Desktop update controls remain reachable above the graph.
