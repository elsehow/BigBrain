# BigBrain 0.9.1

- **A paper you dropped opens as the paper.** When the gardener takes a document as its own subject, so that a dropped paper comes back as an entity named after it, the entity and the paper are now one node in the Field. Clicking it, or picking it in search, opens the paper rather than a page about it. New extractions link themselves. For what's already in your vault, `bigbrain entity bind-sources --dry-run` lists what it would link; run it without `--dry-run` to link them. `bigbrain entity bind-source <entity> <source> --unbind` undoes one.
- **Show sources.** Settings → General → Graph → **Show sources** draws every source in the Field as a faint dot. Point at one to see what it mentions; click it to open it. Off by default.
- **The Field keeps your view.** Panning or zooming no longer snaps back to the overview when the vault changes in the background.
- **Allow the shell where it was refused.** When a Desktop's shell is off and its agent tries a command, the conversation shows the command it wanted and an **Allow shell** button.
- **Agent pages keep the app's theme** in a Desktop's url view again.

Verification: the full engine suite and the desktop's Rust tests pass on the release commit.
