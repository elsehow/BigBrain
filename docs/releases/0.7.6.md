# BigBrain 0.7.6

Memory nodes are easier to recognize: hollow diamonds become filled when
highlighted, their selection outlines are diamonds, and a shaded Memory badge
appears before the title. Badge and title text share the same vertical center.

Hovering any node highlights its visible direct neighbors. The node and its
neighborhood stay highlighted after the pointer leaves, until you hover another
node or change the selection. Transitions fade in and out quickly; shared
neighbors stay lit. Hovering does not move nodes or change the selected notes.

Esc clears the selection and hover highlight, including when the pointer is
still over a node. The cleared node stays quiet until the pointer leaves and
returns. Reduced motion applies these changes immediately.
