# BigBrain 0.7.35

- Shared vaults can take notes you already have. A saved inclusion rule only shares notes that arrive afterwards, so a new shared vault used to stay empty. After you save a rule (or from **Add existing matches** in the shared vault's Inclusion rule tab), BigBrain lists your existing notes that match it. Thumbs up keeps a note, thumbs down leaves it out, and each rating teaches the rule, so later notes are judged the same way. Nothing is shared until you choose **Add**; notes you already shared are skipped.
- To keep this affordable on a large vault, only the 200 notes that best fit the rule's search phrases are checked.

Verification: the full engine suite passes, with new tests for listing, rating, re-checking and adding. The list was tried in the browser on a real vault before release.
