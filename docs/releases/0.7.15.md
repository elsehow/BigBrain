# BigBrain 0.7.15

Pilots now use native Codex tools and approvals, with folder access inherited
from vault Settings. Approval requests and questions appear directly in the
conversation. Intermediate replies remain in the saved history.

The Pilots pane replaces notifications. Press A to open it, use J/K or the
arrow keys to navigate, and Enter to open a conversation. Attention indicators
show which Pilots need you, and closed sessions return to idle.

Paste images into chats and queue follow-up messages while a Pilot is working.
Queued messages appear in gray above the composer, and starting a queued turn
preserves your next unsent draft. Chat headers show selected context without
per-session permission controls.

Unread sources have graph indicators and stay visible in the overview. U
selects unread sources; Shift-U toggles read status from the source text tab.
Idle agents and Pilots share the same graph placement rules, keeping them near
their context instead of stretching the graph.
