# BigBrain 0.7.27

- Connect GitHub in Settings → Connections, or when Pilot asks for repository access. Sign in through your browser or approve an existing GitHub account, choose a repository, and the task resumes.
- Pilot can read issues and pull requests, create issues and comments, fetch and push branches, and open draft pull requests in approved repositories.
- GitHub credentials stay outside the task sandbox. Revoke repository access or disconnect GitHub from Connections at any time.
- GitHub CLI now ships with the desktop app, so connecting does not require a separate installation.
