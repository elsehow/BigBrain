# BigBrain 0.7.25

- Pilot can commit, create branches, and use isolated Git worktrees in folders you add with read/write access. Read-only folders stay read-only.
- Saved native Codex conversations continue through Pi, preserving their history and selected model. Commands use a dedicated open-source sandbox with separate permissions for each session.
- Pilot tables have clear cell borders, spacing, and aligned headers, with horizontal scrolling for wide tables.
- The unfocused message input hides its caret and offers “Talk to the pilot” with the `i` keyboard shortcut. Selected text uses the theme’s active color.
- Selecting or leaving an idle agent no longer makes it active. Activity follows messages and actual work, and open conversations can become idle when their activity window expires.

- Switching agents is faster, with graph preparation reused and mention suggestions loaded when needed.
- Agent connections have visible endpoint dots and quieter resting lines. Hover or select an agent to brighten its connections and show destination labels.
