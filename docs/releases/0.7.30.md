# BigBrain 0.7.30

- Connect shared vaults with an invite link and browse their sources alongside your personal vault. Vault filters also show personal memories linked to shared sources.
- Invite collaborators with read-only or contributor access. Everyone can view the member list; only the owner can invite, change access, or remove members. Invitations work once and expire after 24 hours.
- Teach inclusion rules with examples, using optional Jev credentials or your existing Quick model. Shared vaults and integrations use the same review interface.
- Make integration inclusion rules optional: turn the rule off to include everything. Granola imports transcripts and attendees instead of automated summaries.

Verification: automated engine, browser and macOS native checks cover this release. Fresh installation and invite acceptance in the packaged app on a second Mac have not been verified; this release proceeds with that limitation documented.
