# BigBrain 0.8.0

- **Field is the whole app.** Every window opens to the 3D view of your vault, and the Classic view is gone. A citation opens its note beside the chat, and ⌘O opens a source's original. Action history and old pre-Pilot conversations went with Classic.
- **Desktops.** An agent chat is now a Desktop: the conversation plus any notes or pages the agent shows beside it. ⌘N starts one. Shift+Enter starts one on whatever you have open, already read in. Type @ to mention a recent item or search the vault.
- **Coding desktops.** A Desktop's agent can work in your project checkouts, starting its own branch only when needed. Land or Discard its work from the header.
- **The feed** updates live. j/k walk it and light the entities each item concerns; Enter opens the source in a reader view.
- **Search** lists recent items before you type and finds entities by any of their names.
- **Press ?** for every shortcut that works right now. Settings → General keeps only the switch for on-screen key hints.
- **Intake firewall.** With a Jev key set, every arrival is screened first. Password-reset links, sign-in codes, keys and passwords are withheld, so no agent reads them. Switch it off in Settings → Security, which also controls loading remote pages and images.
- **Skip rules are gone, and so are inclusion rules for your own accounts.** Every connected account is remembered; disconnect one to stop it. Mail your skip rules dropped now reaches the gardener. To filter it, turn on the optional worth gate (`gate:` in `vault.yaml`), which learns from what the gardener files. Shared-vault inclusion rules remain, now offering likely matches first and letting you add a note by hand.
- **New sources:** RSS and Atom feeds (Settings → Integrations → RSS). Granola can import earlier meetings and no longer misses ones held while disconnected.
- **Shared vaults** blend into one field: an entity both vaults know is one dot. The vault switcher is gone.
- **Merge?** An entity that looks like a duplicate offers Accept or Reject for each merge.
- **Memory is one file,** `memory/MEMORY.md`. It rebuilds on its first run after the update; old files are backed up.
- **Out of usage credits** shows a banner with Retry, and background filing pauses until credits return.

Verification: the full engine suite (2140 tests) and all 21 browser scenarios pass on the release commit. Field, search, the feed walk, Merge? and one-entity-across-vaults were tried in the browser, and the cross-vault merge on a real vault, before release.
