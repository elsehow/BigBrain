# BigBrain 0.7.8

Pilot conversations now keep their own graph context and history, with searchable
mentions, resizable conversation tabs, and smoother navigation between sessions.

Pilot can now inspect local projects, read and edit files, and run commands
before deciding whether to delegate. It uses what it learns to choose the right
project and passes relevant findings to its workers. Longer tasks can continue
in a worker while Pilot stays available.

Pilot and workers share the folder authorizations in Settings → Vault → Agent
access. Each session gets only the folders its task needs, with read-only or
read-and-write access. Authorized access proceeds automatically; additional
access pauses the session and asks you in its conversation. The Access menu
shows grants, lets you revoke them, and offers unrestricted access for an
individual session. Pending requests survive restarts. The old global Cowboy
setting no longer makes new sessions unrestricted.

Pilot's local commands use the installed Codex sandbox runtime across Pilot
backends, without making model calls. Worker access rules apply consistently to
Codex and Claude. Pilot receives complete saved worker transcripts when reporting
results, so its updates retain more of the findings and validation.

Source unread state now stays in sync in both directions, and Pilot questions
and updates persist as notifications. The unfinished Voice section has been
removed from Settings.
