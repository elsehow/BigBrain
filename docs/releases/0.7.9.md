# BigBrain 0.7.9

Unread View opens faster, and unchanged background session refreshes no longer
rebuild the graph and interrupt interaction. Graph appearance is preserved.

Pilot can finish longer tasks without arbitrary tool-call, round, or whole-turn
time limits. A Stop button in the text conversation header interrupts the active
Pilot turn while keeping the conversation open. Press Command-period on Mac
(Control-period elsewhere) to stop, including while typing. The separate End
session control retains the connected-worker shutdown flow.

Settled agents no longer leave unnecessary labels on the graph.
