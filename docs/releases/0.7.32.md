# BigBrain 0.7.32

- Memory updates no longer time out. Background jobs can run for up to an hour instead of 20 minutes, and the memory pass trims its notes by editing passages instead of rewriting whole files. If an earlier failed run left half-finished edits in your vault's `memory/` folder, discard them with `git checkout -- memory/` in the vault.
- With a Claude subscription, the recommended gardener is now Sonnet 5.5. In an offline comparison on real searches it built entity pages that served name lookups as well as before, at about a sixth of the cost. A gardener model you chose yourself is kept.
- Newer Claude models, including Sonnet 5.5 and Opus 5.5, are available from first launch, without first downloading the online model catalog.
- Agents searching your vault are told that search matches words literally, and are asked to try several phrasings for topical searches.

Verification: automated engine checks cover this release. The browser suite failed intermittently on unrelated interface timing tests, and one change was merged over such a failure. The new memory-pass limits have not yet completed a run on a real vault, and Pilot, memory and Quick on the upgraded model runtime were not exercised in the packaged app; this release proceeds with those limitations documented.
