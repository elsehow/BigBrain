# BigBrain 0.7.19

Active agents now bring their immediate context forward in the graph.
Their connections remain visible as dashed lines, while unrelated nodes
sit lower and dimmer. The normal overview returns when the agents finish.

Pilot shows its activity inline, and its roster keeps a stable creation
order. Draft sessions closed with Shift–Esc no longer appear in Recents;
unsent text remains available through search.

Recommended models refresh when connected providers become available or
unavailable, while explicit model choices are preserved.
