# BigBrain 0.7.14

Selecting a Pilot or any of its agents now keeps one shared graph view, with
the same visible nodes and camera framing.

Worker alerts and Pilot notifications use the same card and navigation.
Long messages stay truncated, dismiss buttons remain inside the window,
and clicking an alert opens its conversation and marks it seen.

New shortcuts: N opens notifications, arrows or J/K navigate, Enter opens
the selected notification, C clears notifications while the pane is open,
and U selects all unread sources. These keys are listed in Shortcuts settings.
Clearing notifications does not answer or resolve outstanding questions.

Session headers omit the Context and Access prefixes and hide their status
labels in narrow panels. Shortcuts settings also has less explanatory text.
