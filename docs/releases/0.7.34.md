# BigBrain 0.7.34

- Inclusion-rule reviews suggest better examples for broad rules. A rule like "shared family concerns" used to surface anything with the word "family" in it; its search phrases are now the concrete things such notes discuss (appointments, childcare, benefits, household costs) rather than rewordings of the rule.
- Long agent transcripts no longer crowd the top of a review just by mentioning a little of everything; a short note about the topic ranks above them.
- The rule editor waits for a real pause (about two seconds) before re-evaluating as you type, instead of restarting the review mid-sentence.

Verification: the full engine suite passes. On a real vault, the first suggestions for "shared family concerns" became clinic appointments, family benefits, a care provider and a child-care waitlist instead of coding sessions, and a will rule's first suggestion became the estate-documents thread; both were tried in the browser before release.
