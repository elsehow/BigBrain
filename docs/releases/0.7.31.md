# BigBrain 0.7.31

- Selecting an item opens a compact graph of relevant connections, ranked relative to that selection. Shared nodes keep their places as you explore neighboring items.
- Graph transitions fade departing nodes, reveal sparse edges, and introduce a few persistent landmark labels as the layout settles. Reduced-motion preferences are respected.
- Keyboard navigation at home preserves the familiar pan and depth effect. Mouse inspection highlights items without replacing the keyboard-framed view or moving a node away from the pointer.
- Relationship lists use consistent typography, edge-to-edge black-and-white selection, and the same scrollbar as Recents and Agents. Note action buttons share a common size and weight.
- An empty vault's home screen invites a first drop, with a link to Integrations, instead of showing a blank canvas.
- Join a shared vault during setup by pasting its invite link. Connecting, during setup or from Settings, opens the vault's home with its sources listed. Until you have memories, the graph labels entities and uncited sources so a new vault is visible. Shared sources open on their text instead of an unavailable briefing.
- Memory now covers every shared vault you have joined, so a member with an empty personal vault still gets memory once the vault holds claims. Memory cites shared claims and the graph links those memories to the shared entities.
- Contributing sources to a shared vault also shares your vault's claims about them, but only claims whose sources were all contributed. They are posted by your app as your agent, keep a person's name only when the sources contain it, and are retracted if you withdraw a source. This requires a shared vault server running the same release.

Verification: automated engine, browser and macOS native checks cover this release, and the shared vault server update was smoke-tested on its host before deployment. Joining a shared vault and memory over it in the packaged app on a second Mac have not been verified; this release proceeds with that limitation documented.
