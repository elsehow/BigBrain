# BigBrain 0.7.31

- Selecting an item opens a compact graph of relevant connections, ranked relative to that selection. Shared nodes keep their places as you explore neighboring items.
- Graph transitions fade departing nodes, reveal sparse edges, and introduce a few persistent landmark labels as the layout settles. Reduced-motion preferences are respected.
- Keyboard navigation at home preserves the familiar pan and depth effect. Mouse inspection highlights items without replacing the keyboard-framed view or moving a node away from the pointer.
- Relationship lists use consistent typography, edge-to-edge black-and-white selection, and the same scrollbar as Recents and Agents. Note action buttons share a common size and weight.
