# BigBrain 0.5.0

Explore the graph one connection at a time. Hovering a note brings its direct connections to a shared surface; moving to a neighbor reveals that neighbor's connections while shared notes stay in place. The neighborhood stays open while you cross the space between notes.

- A compact overview, smooth depth transitions, and motion trails make the graph easier to browse. Opening a note frames its direct connections.
- Pilot brings voice and text conversations into the main window and can delegate work to persistent Claude Code and Codex sessions. Running agents and requests for input appear alongside the graph and recent sources.
- Search includes memory notes and source threads, with shared name matching and ranked connection navigation.
- Recent items and opened notes show clearer source and agent provenance. Desktop routes and engine identity checks keep the app connected to its own engine.
