# BigBrain 0.7.18

Connect your model providers in Settings → Models, then choose models for
Pilot, gardening, memory, and quick tasks. Provider connections and folder
permissions now live together in a simpler settings layout. You may need
to sign in to your provider again after updating.

Search, note opening, and graph/feed preparation are faster and do less
work while idle. Cold feed preparation runs in the background, gardening
shows live progress, and filesystem watching recovers from transient errors.
Entity matching now handles non-Latin names and prepares labels once per
submission batch.

First-time setup includes a discreet theme picker and an optional usage-data
prompt. Performance diagnostics are available in Settings → Diagnostics,
where usage sharing can be turned off at any time. Sharing is opt-in and
excludes vault content and metadata.

Automatic capture of external agent chats has been removed. Pilot remains
the app's conversation surface, and connected agents use shared vault tools.
