# Retired project workers

BigBrain no longer launches or runs connected agents. Pilot remains available
for knowledge conversation, evidence retrieval, and preparing context for your
own external agent. Use Settings → Connected Clients to connect that agent to
BigBrain through MCP. The agent application owns execution and its permissions.

Connected Agents / Agent Orchestration settings, project environment setup,
worker approval cards, follow-ups, command credentials, and automatic worker
report processing have been removed. There is no hidden execution toggle.

Existing worker transcripts, working-folder paths, and operation records remain
readable. On read, running tasks appear interrupted, started operations appear
uncertain, and undelivered steering appears withdrawn. Access requests cannot be
approved and worker reports cannot start a model. Original worker records,
workspaces, and saved environment data are left on disk; none is used to execute
work. Inspect old working folders with your own tools if you need their results.

Legacy native conversations retain their existing historical Pilot redirects.
Retired Pi workers remain read-only conversations with their operation history.
