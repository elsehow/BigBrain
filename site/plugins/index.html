Before you start

Install and open the BigBrain desktop app, then create your vault. Keep the app running when you capture. Updating from the old hosted version? Pair with your desktop app again.

Then pair it

  1. In BigBrain: settings → integrations → PAIR A BROWSER. A code appears — ten minutes, one use.
  2. In the extension's options (right-click its toolbar button → Options): leave the address at http://127.0.0.1:4748, enter the code, Connect.

By default, captures go to BigBrain on this machine at 127.0.0.1. If you configure a different address, captures go there. Pair each browser once; BigBrain's integrations card lists every browser that has, and REVOKE there is disconnect.
